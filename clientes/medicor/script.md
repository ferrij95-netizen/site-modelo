# Medicor Produtos Hospitalares · script de ligação

**Quem:** Medicor Produtos Hospitalares Ltda, distribuidora de descartáveis para a saúde em Porto Alegre (Sarandi) desde 1993, com marca própria RMDESC (seringas, equipos, linhas de hemodiálise, EPI). Fone (51) 3344-8384, WhatsApp comercial (51) 99365-7955.

**Problemas reais do site atual (medicor-rs.com.br):**
- Feito em 2012 (WordPress 3.4), largura fixa de 940 px: no celular o comprador precisa dar zoom para ler a ficha do produto.
- Sem HTTPS: o navegador marca "Não seguro", e os PDFs de documentos podem ser bloqueados no download.
- Na página Downloads a "Autorização de funcionamento" não abre (link vazio) e os alvarás publicados são de 2021/2022.
- O catálogo RMDESC em PDF tem 16 MB.

**O apelo:** o comprador do hospital acha o produto pela área (hemodiálise, infusão, EPI), vê código, modelo e registro ANVISA, monta a cotação no site e manda pronta no WhatsApp comercial. A documentação para cadastro de fornecedor fica organizada para baixar.

Montei uma versão nova da Medicor, já está no ar num link de prévia: os 31 produtos RMDESC com código e registro ANVISA, cotação que chega pronta no WhatsApp de vocês e os documentos organizados para o cadastro de fornecedor. Posso mandar o link?"
