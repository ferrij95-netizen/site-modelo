Como medir aChapa expandida

A chapa expandida tem muitas aplicações, por isso é preciso saber calcular as suas dimensões para escolher o material certo para cada projeto. O principal cuidado é a adequação ao estado-limite, ou seja, à resistência mecânica do material: uma malha mais aberta pode servir para uma grade, mas não para um piso, que se deformaria com o tráfego de pessoas. Medir corretamente evita desperdício, custo desnecessário e retrabalho.
