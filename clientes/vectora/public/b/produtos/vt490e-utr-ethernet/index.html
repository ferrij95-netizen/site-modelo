VT490E UTR (Ethernet)

O VT490E é uma Unidade Terminal Remota (UTR) microprocessada com interface Ethernet. Trabalha com os protocolos Modbus/TCP, HTTP e HTTPS e por isso se integra a qualquer sistema de supervisão compatível com Modbus/TCP, como o Elipse e os sistemas SCADA em geral.

Solicitar orçamento Todos os produtos

Características

  • Canais de vazão pulsados
  • Entradas digitais
  • Entradas analógicas 4 a 20 mA
  • Sensor de pressão interno ao gabinete
  • Canal de comunicação Modbus para leitura de até 5 variáveis
  • Interface de configuração USB
