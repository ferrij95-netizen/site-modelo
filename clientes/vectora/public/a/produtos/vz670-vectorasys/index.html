Sistema Web

VZ670 VectoraSys

O VectoraSys é o sistema web da Vectora Indústria para gerenciamento, monitoramento e controle dos equipamentos. Pode ser acessado de qualquer computador com internet, o que facilita a supervisão e a administração dos equipamentos instalados em campo.

Solicitar orçamento Todos os produtos

Características

  • Compatível com os principais navegadores do mercado
  • Exportação de dados em XLS, TXT, CSV e XML
  • Telas personalizáveis
  • Unidades de medida configuráveis
  • Idioma, padrão de telas e formato de data configuráveis
  • Quatro perfis de acesso de usuário
  • Registro das ações dos usuários em log
  • Geração de arquivos de configuração para atualizar os equipamentos em campo

Equipamentos, sistemas e projetos customizados de telemetria para saneamento, indústria e óleo e gás.
