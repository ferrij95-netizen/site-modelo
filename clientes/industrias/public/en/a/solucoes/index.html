Frequently asked questions

What manufacturers usually ask.

All questions
Can our PDF catalog become an online catalog?

Yes. We start from your current catalog, organize the lines and create one page per product, with a spec sheet and a quote request.

Can you build the website in more than one language?

Yes, with reviewed translation of the technical copy and a language switch on every page.

Do we need to photograph the plant?

We use the photos you already have. If something is missing, we tell you what is worth shooting and mark where an image is a placeholder.
