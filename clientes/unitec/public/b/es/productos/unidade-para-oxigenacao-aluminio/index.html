Terapia Respiratoria

Unidad para Oxigenación en Aluminio

Unidad movil/portatil para el uso con oxígeno suplementario, para mantener o aumentar el nivel percentual diagnosticado al paciente.

Ensamblada con cilindro de aluminio de alta calidad, es más práctica para el transporte

y uso en residencias, clínicas y hospitales.

Se encuentra en el kit básico:

- Cilindro de oxígeno de aluminio;

- Válvula reguladora con flujómetro de oxígeno (VF010);

- Conjunto para humidificación 250 ml con máscara adulto (UD111);

- Catéter nasal tipo gafas (CT010).

(Las unidades de transporte son opcionales)
