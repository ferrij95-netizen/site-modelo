Emergencia y Rescate

Cánula de Guedel (Orofaríngea)

Las cánulas de Guedel fueron desarrolladas y fabricadas para pacientes que necesitan maniobras en las vías aéreas, evitando la obstrucción.

El dispositivo se utiliza para proteger el tubo endotraqueal, permitiendo una mejor oxigenación y aspiraciones frecuentes.
