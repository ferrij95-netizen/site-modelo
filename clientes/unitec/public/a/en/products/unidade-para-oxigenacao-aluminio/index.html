Respiratory Therapy

Aluminum Oxygenation Unit

Mobile/portable unit for administering supplemental oxygen, to maintain or raise the percentage level prescribed for the patient.

Built around a high-quality aluminum cylinder, it is a more practical solution for homes, clinics, medical offices, hospitals and other settings.

The basic kit includes:

- Aluminum oxygen cylinder

- Regulator with oxygen flowmeter

- 250 ml humidification set with adult mask

- Nasal cannula (glasses type)

Optional accessories:

Nylon case

Nylon case with wheels

Cylinder transport trolley
